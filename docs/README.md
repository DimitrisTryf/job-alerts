# Project research notes

These files are reference material and are not read by the application:

- `not_implemented.txt`: companies whose reliable employer-controlled feed has
  not been implemented.
- `locations.txt`: historical raw locations collected during filter design.
- `locations-left.txt`: historical locations remaining after the initial
  exclusion pass.
- `location-filter-review.txt`: the manual location-classification review that
  produced the initial exclusions.

Runtime configuration remains under `telegram-bot/`, next to the code that
loads it.
